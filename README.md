# Study Sprout

A hackathon application that turns study notes into a manageable plan and practice quizzes.

**Live app:** [Open Study Sprout](https://study-sprout-journal.saltyegret15.chatgpt.site/)

**Judge entry:** [Repeatable judge demo](https://study-sprout-journal.saltyegret15.chatgpt.site/?judge=1). Uses fictional notes and separate progress. Reset affects only this demo; it also refreshes on a new day so the exam stays in the future. Offline planning needs no account or API. Deployment of repository changes must be verified separately.
